A simple **C++ console-based Contacts Manager** developed as a college project.

## 📌 About The Project

Contacts Manager is a simple program that allows the user to manage a list of contacts through a console-based menu.

The project was developed to practice basic **C++ programming and Object-Oriented Programming (OOP)** concepts.

## ✨ Features

* Add new contacts
* Display all contacts
* Search for contacts by name
* Update contact information
* Delete contacts
* Count the number of contacts
* Mark contacts as favorites
* Display favorite contacts
* Basic input validation

## 📋 Contact Information

Each contact can contain:

* Name
* Phone number
* Gmail
* Address
* Favorite status

Gmail and address are optional.

## 🛠️ Technologies Used

* C++
* Object-Oriented Programming (OOP)
* Classes
* Arrays
* Loops
* Conditional statements
* Switch statements

## ▶️ How To Run

1. Download or clone the repository.
2. Open the project files using a C++ IDE such as **Code::Blocks**.
3. Make sure `Contacts_Manager.cpp` and `contactmanager.h` are in the same project.
4. Build and run the program.
